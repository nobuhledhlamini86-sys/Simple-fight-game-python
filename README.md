# Fight Club - Python Text Game 🎮

A fun command-line fighting game built in Python! Player vs Enemy battle with health, damage, dodge and heal.

Built with ❤️ in Bloemfontein on Proline Laptop

## Gameplay
- Start with 100 Health each
- You choose:
    1. Kick (10-20 damage)
    2. Punch (10-20 damage) 
    3. Jump (50% chance to dodge enemy)
    4. Heal (10-20 health)
- Enemy counter-attacks every turn
- First to 0 health loses!

## Tech Stack
Python | Random Module | While Loops | Game Logic | Health System

## How to Run (Locally)
This is a Python script (.py file).

1. Download `fightclub.py`
2. Open terminal
3. Run:
```bash
python fightclub.py
